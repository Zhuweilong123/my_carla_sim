# 执行器适配第一轮：从理想转角到受限执行器

日期：2026-09-19。基线提交：`784c1d5`。实验执行时为该提交后的工作区，
实际代码由每份 JSON 中的源码哈希和 `sources/*.zip` 识别。

## 范围与参数来源

本轮新增转向执行器、相应增广 LQR、共享参数接口、ROS 接入和测试；没有修改道路、
降低目标速度、修改纵向 PID 或替换车辆轮胎模型。全部闭环目标 50 km/h，dt=0.05 s，
稳态窗口为 10 秒之后，误差仍使用 `route_projection_v2`。

**没有实车标定数据。下面全部是显式工程假设，不代表任何具体车型。**

| 参数 | 假设值 | 单位 / 含义 |
| --- | ---: | --- |
| 纯输入延迟 | 0.05 | s，命令延迟一个控制/物理周期 |
| 一阶时间常数 | 0.15 | s，转向惯性 |
| 实际前轮角速率上限 | 0.6 | rad/s，约 34.38 °/s，不是方向盘角速率 |
| 实际前轮角幅值上限 | 0.5 | rad，约 28.65°，沿用车辆参数 |
| 车辆质量/质心/侧偏刚度/惯量 | 沿用现有参数 | 仅集中管理和校验，未重新辨识 |

入口：`ScenarioConfig.vehicle_params` 与 `ScenarioConfig.steering`；`SteeringParams.source`
明确标记 `engineering_assumption_not_vehicle_calibrated`。
默认 `ideal` 模式保留旧基线。`assumed` 模式需显式启用，不将假设参数默认为真实车辆。

## 实现与控制器适配

1. 请求前轮角先经过外层周期 FIFO 延迟，然后在物理子步推进执行器。
2. 动态执行器满足 `dδ/dt = clip((δ_delayed-δ)/τ, -rate, +rate)`，
   对固定目标使用限速段与指数响应段的解析解；并非只裁剪日志中的转角变化率。
3. `VehicleState.steer` 和 ROS 状态中的转角是**实际前轮角**，控制输入仍是请求角。
4. LQR 增广状态为 `[ed, ed_dot, ephi, ephi_dot, actual_delta, delayed_commands...]`，
   执行器角和命令队列以当前曲率前馈为平衡点。矩阵包含一阶动态和整数周期延迟，
   不包含激活的非线性速率饱和；并未升级为硬约束 MPC。
5. 使用实际转角反馈；缺少该反馈时拒绝运行执行器感知控制，而不是假设请求已执行。
6. Q 保持 diag(200,1,50,1)，增广维度的直接代价为零；最终受限模式 R=300，理想模式 R=100。
7. 复位清空执行器和控制器队列，普通路径更新保留队列。ROS context 同步参数，
   执行器 profile 仅启动时可选；运行中修改被拒绝，以避免两端不一致。

延迟要求是外层周期的整数倍，不支持任意连续延迟，也不自动取整。
控制预测队列假设每个固定物理周期执行一次命令；ROS 检测状态时间缺口后锁存保持角度/制动请求，
直至新 run/reset。尚无执行器命令 ACK、网络丢命令恢复或真实时间调度保证。

## 首先确认：旧控制器不能直接迁移到新执行器

| 同一 30 秒试验计划 | 运行结果 | 稳态横向 RMS | 说明 |
| --- | --- | ---: | --- |
| 理想执行器 + P2 控制器 | 完成 30 s | 0.01615 m | 精确复现 P2 30 秒基线 |
| 受限执行器 + P2 控制器 | 4.8 s 越界 | 不存在稳态窗口 | 失败数据已保存，不能与完整运行按 RMS 排名 |
| 同一受限执行器 + 增广 LQR R100 | 完成 30 s | 0.03370 m | 支持执行器适配的有效性 |

这个对照证明的是“适配优于对新对象不作适配”，不是“新物理模型比理想模型误差更小”。

## 为什么最终选 R300，而不是标称精度更好的 R100

| 相同对象/相同运行范围 | R100 | R300 |
| --- | ---: | ---: |
| 标称十圈稳态横向 RMS m | 0.03585 | 0.04645 |
| 标称十圈稳态航向 RMS ° | 1.53526 | 1.51915 |
| 标称十圈稳态实际转角变化率 RMS °/s | 6.98490 | 5.14834 |
| 更快执行器三圈：稳态横向 RMS m | 0.04774 | 0.03958 |
| 更快执行器三圈：实际转角变化率 RMS °/s | 32.24135 | 7.96686 |
| 更快执行器三圈：触发物理速率限制的周期占比 | 85.814% | 2.193% |

“更快执行器”是对象 τ=0.10 s、延迟=0，而控制器仍按 τ=0.15 s、延迟=0.05 s 设计。
R100 虽然跑完，但持续触碰速率限制，不能判为控制品质合格。
R300 降低这一失配下的振荡，代价是标称横向 RMS 增加约 1.06 cm。
因此保留 R100 数据但选择 R300，并非宣称所有指标或全部不确定性下均最优。

## 最终结果（final300）

| 工况 | 圈数/终止 | 稳态横向 RMS m | 稳态实际转角变化率 RMS °/s | 速率限制触发占比 |
| --- | --- | ---: | ---: | ---: |
| 理想基线 | 10 圈 | 0.01691 | 19.5553 | 不适用 |
| 受限未适配 | 4.8 s 越界 | 不适用 | 不适用 | 46.875% |
| 受限适配，标称 | 10 圈 | 0.04645 | 5.1483 | 0.127% |
| 位置噪声 σ=0.05 m，seed=2026 | 3 圈 | 0.04946 | 14.4921 | 5.086% |
| 初始横向 0.5 m、航向 5° | 3 圈 | 0.04657 | 4.9572 | 0.700% |
| 对象更慢：τ=0.20 s、延迟=0.10 s | 3 圈 | 0.05638 | 4.5751 | 0% |
| 对象更快：τ=0.10 s、延迟=0 | 3 圈 | 0.03958 | 7.9669 | 2.193% |
| 质量 +10%、侧偏刚度幅值 -10% | 3 圈 | 0.03520 | 4.9648 | 0.093% |

最终适配配置及五组扰动全部通过路线/运行检查，物理执行器约束违反次数为零。
标称十圈为 7099 步 / 354.95 s，峰值速度 50.51848 km/h。
瞬时实际速率上限为 34.38 °/s，标称记录到的控制周期平均峰值约 34.23 °/s。

**约束不超限与从不触发限制是两回事。** 本轮的物理对象会主动限速，控制器仍可能请求超快变化。
标称请求角变化率峰值仍约 141.14 °/s，更快执行器失配时请求峰值约 469.05 °/s；
不能把实际角被执行器平滑后的数值当作命令已经满足硬速率约束。

## 尚未解决的限制

- 本轮不是实车标定或完整动力学真实性升级。轮胎仍为线性模型，没有附着圆约束。
- 标称横向加速度诊断峰值仍约 13.96 m/s²；更快执行器失配的全程峰值约 28.84 m/s²。
  这些结果不能解释为真实车辆可安全完成该速度下的路线，后续需可行速度规划与轮胎约束。
- 仍使用理想状态反馈（位置噪声实验除外），没有完整状态估计或传感器时间对齐。
- 起步速度误差没有解决：标称全程速度误差 RMS 约 1.46635 km/h。
- 标称平均控制耗时约 2.00 ms，相比理想基线约 1.19 ms 增加；不同运行负载下不能作精确复杂度结论。
- 仅一个噪声种子、少量失配配置，不能声称全面鲁棒。低速模型切换、手动接管后恢复和全部场景仍需专项验证。
- 新 LQR 针对采样线性化与标称执行器设计，速率饱和期间无全局稳定性保证。

ROS / GUI：

```bash
source /opt/ros/lyrical/setup.bash
```

如需映射真实车型，应先获取可验证的执行器数据，而不是直接把该 profile 改名为已标定。

## 验证记录与字段说明

最终完整测试 **57 项通过，0 失败、0 错误、0 跳过**（`tests01.xml`）。WSL ROS 构建通过。
理想 DDS 十圈完成 7103 步 / 355.15 s，受限 DDS 十圈完成 7099 步 / 354.95 s；
两种模式均通过复位与场景切换，独立进程均运行至至少 15 s 并核对状态/命令。
归档复核通过：27 次闭环和 4 组 ROS 的样本数、参考点数及源码 ZIP 哈希一致；
最终 `final300` 和 ROS 快照中的源码与提交前工作区一致。
27 次闭环中有 4 次预期失败（各前缀的 `_unadapted`），其余均通过运行门槛；不隐去失败结果。

- 单元测试覆盖延迟 FIFO、解析阶跃、速率边界与反向响应、子步划分不变性、参数检查、
  复位与路径刷新。数值测试用中央差分核对增广模型 A/B、DARE 残差和局部闭环谱半径。
- ROS 验收分别覆盖 ideal/assumed 十圈、reset/场景切换、独立进程启动，以及时间缺口锁存制动。
- `ros_acceptance01/` 保存 ROS 验收原始状态、命令、实际转向及切换事件；`tests01.xml` 为测试报告。
- `steer_rate_deg_s` 是实际前轮角控制周期平均变化率；`command_steer_rate_deg_s` 是请求角变化率。
- `actuator_peak_rate_rad_s` 是模型在周期内记录的瞬时最大物理角速率。
  早期 ideal 档案的该字段为 0（未启用），不是“实际转角不变”；最终 summary 对 ideal 使用 null。
- `steer_saturation_fraction` 沿用历史含义：请求角幅值饱和；最终另存实际角幅值饱和和执行器速率限制比例。
- 所有 `passed` 都不代表真实车辆安全性或物理附着可行性。失败基线是预期对照，不应删掉。
